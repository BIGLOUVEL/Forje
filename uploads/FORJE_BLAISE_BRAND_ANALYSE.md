# PARTIE A — LA PLATEFORME DE MARQUE (théorie appliquée aux médias)

Une identité visuelle sans plateforme de marque est une décoration.
Blaise construit dans cet ordre : PLATEFORME → NOM → VISUEL.
(En pratique conversationnelle il peut zigzaguer, mais il sait toujours
quelle brique manque.)

## Les 6 briques

```
1. MISSION       Pourquoi ce média existe (une phrase, pas un poème)
2. CIBLE         Pour qui, formulé de façon actionnable (voir Partie C)
3. POSITIONNEMENT Ce qui le rend seul de son espèce (voir Partie C)
4. PERSONNALITÉ  L'archétype + 3 traits (voir ci-dessous)
5. VOIX & TON    Les 4 curseurs (voir Partie C)
6. PREUVE        Ce qui rend la promesse crédible (rythme, exclus, format
                 signature, expertise)
```

## Les archétypes de personnalité appliqués aux médias

Grille de Jung (12 archétypes), avec les correspondances observées :

```
LE REBELLE (Outlaw)    Vice, So Foot        — casse les codes, irrévérence
L'HOMME DU PEUPLE      Brut, 20 Minutes     — accessible, du côté des gens
LE SAGE                Le Monde, Vox, Axios — comprendre, expliquer, nuancer
LE BOUFFON (Jester)    Konbini, Oh My Goal  — le plaisir d'abord, complicité
L'EXPLORATEUR          Morning Brew, Sifted — découvrir avant les autres
LE HÉROS               L'Équipe, ESPN       — la performance, le dépassement
LE CRÉATEUR            Pitchfork, The Fader — le goût, la curation pointue
LE SOUVERAIN (Ruler)   Bloomberg, Les Échos — l'autorité, la référence
LE MAGICIEN            The Verge            — la tech qui transforme
LE PROTECTEUR          Franceinfo           — fiabilité, service public
```

Usage par Blaise : identifier l'archétype dominant (+ un secondaire max)
en début de conversation marque. L'archétype ALIGNE ensuite tout :
- Rebelle → N&B brut, typographie qui gratte, ton cash
- Sage → sobriété, sérif possible, ton pédagogue
- Bouffon → couleurs franches, formes rondes, ton complice
- Héros → italique vitesse, rouge, superlatifs maîtrisés
Un média qui mélange 3 archétypes n'en a aucun.

## Le test de cohérence final

"Si on masque le logo, est-ce qu'on reconnaît le média à un post ?"
La marque est faite de récurrences : même signature couleur, même voix
de titre, même grammaire de layouts. C'est exactement ce que Forje
industrialise — Blaise doit le rappeler quand un client veut changer
de style toutes les semaines.

# PARTIE B — NAMING : 25 NOMS ANALYSÉS

Grille : pattern / mécanique / pourquoi ça marche / leçon.

**1. Brut** — Mot court détourné. "Brut" = sans filtre, sans montage.
Le nom EST le positionnement éditorial en 4 lettres. Leçon : le meilleur
nom est une promesse compressée.

**2. Konbini** — Emprunt culturel (supérette japonaise ouverte 24/7).
Exotique, prononçable, et le SENS (tout, tout le temps, accessible)
correspond au produit. Leçon : un emprunt fonctionne si la métaphore
travaille pour toi.

**3. Loopsider** — Mot-valise (loop + insider). Double sens : la boucle
de l'info + l'initié. Leçon : un bon mot-valise se décode en une seconde
mais récompense la réflexion.

**4. Explicite** — Mot du dictionnaire à double lecture (clair / cru).
Positionnement de transparence encodé. Leçon : chercher les mots qui ont
déjà deux sens utiles.

**5. Legend** — Mot aspirationnel court. Marche pour un média d'interviews
(les "légendes" reçues). Leçon : le nom peut désigner l'INVITÉ/le sujet,
pas le média lui-même.

**6. HugoDécrypte** — Prénom + verbe d'action. La marque incarnée parfaite :
QUI + CE QU'IL FAIT. Leçon : pour une marque personnelle, prénom + promesse
bat tous les noms abstraits.

**7. Booska-P** — Argot communautaire + initiale. Signal d'appartenance
immédiat pour la cible rap. Leçon : un nom "interne" à la communauté crée
l'adhésion mais ferme l'extérieur — choix assumé.

**8. Footmercato** — Descriptif composé (niche + sous-niche). Zéro poésie,
100% clarté SEO. Leçon : le descriptif marche pour capter une INTENTION
(le mercato) mais n'est pas défendable comme marque — le volume compense.

**9. Oh My Goal** — Détournement d'expression (Oh My God). Émotion du but
encodée, mémorisation immédiate, international. Leçon : détourner une
expression universelle = mémorable et traduisible.

**10. 433** — Code communautaire chiffré (la formation 4-3-3). Les initiés
comprennent, les autres demandent — les deux créent de l'engagement.
Leçon : un code chiffré de la niche est un mot de passe communautaire.

**11. Overtime** — Terme du jeu chargé d'intensité (prolongation).
Court, énergique, marchandisable (merch OT). Leçon : penser au nom SUR
un hoodie dès le naming — le média social-first est une marque streetwear.

**12. GOAL** — Mot générique de la niche. Clarté absolue, différenciation
nulle : tout repose sur l'exécution. Leçon : possible seulement en arrivant
tôt ou massivement — Blaise le déconseille à un nouveau média.

**13. SPORF** — Néologisme (sport + f). Ownable à 100%, zéro concurrence
SEO, handle libre garanti. Leçon : le néologisme court est l'option la plus
sûre juridiquement et digitalement.

**14. DAZN** — Néologisme phonétique ("da zone"). Prononciation à
apprendre = friction initiale, distinctivité maximale ensuite.
Leçon : un nom-phonème exige un budget de notoriété ; pour un petit média,
préférer la lisibilité immédiate.

**15. House of Highlights** — Expression de la communauté (le "crib" des
highlights). Long (17 lettres) → symbole d'avatar obligatoire dès le jour 1.
Leçon : un nom long peut vivre si le CONCEPT est fort et le monogramme prêt.

**16. Bleacher Report** — Métaphore d'appartenance (les gradins = les vrais
fans) + mot média (report). Leçon : situer le média DU CÔTÉ du public dans
le nom même.

**17. Morning Brew** — Rituel + objet (le café du matin). Le nom programme
l'USAGE quotidien. Leçon : encoder le moment de consommation dans le nom
crée l'habitude.

**18. Axios** — Mot grec ("digne de"). Court, sérieux, sonorité tech.
Leçon : les langues anciennes donnent des noms courts, ownables et
chargés — vérifier le sens réel avant (pièges de traduction).

**19. Vox** — Latin ("voix"). 3 lettres, autorité douce. Même leçon
qu'Axios : l'étymologie comme gisement de noms courts.

**20. NowThis** — Injonction temporelle (maintenant, ça). L'urgence
encodée dans la syntaxe même. Leçon : un nom peut être une phrase-réflexe.

**21. Vice** — Mot interdit assumé. Positionnement rebelle en un mot.
Leçon : le nom-provocation fonctionne si TOUT l'édito suit — sinon c'est
un costume.

**22. Genius** — Promesse superlative (comprendre les textes = génie).
Leçon : un nom aspirationnel doit être tenu par le produit (les
annotations) sinon il sonne arrogant.

**23. Pitchfork** — Objet-symbole (la fourche : piquer, retourner).
Le nom DESSINE le logo (le P-fourche). Leçon : le graal — chercher un nom
qui contient déjà sa forme visuelle.

**24. Hypebeast** — Argot de la niche (le "hypebeast" = l'accro au drop).
Nom = le lecteur lui-même. Leçon : nommer le média comme sa cible se
nomme elle-même = miroir communautaire puissant.

**25. Sifted** — Participe évocateur (tamisé = l'info triée). Média FT
sur les startups : le tri est la promesse. Leçon : les participes anglais
courts (sifted, wired, verged) portent une action subie par l'info —
gisement de naming pour médias de curation.

## Synthèse naming

```
PATTERNS PAR FRÉQUENCE D'USAGE ET DE SUCCÈS
Mot détourné / double sens     ★★★★★  (Brut, Explicite, Vice)
Mot-valise décodable           ★★★★   (Loopsider, SPORF)
Code communautaire             ★★★★   (433, Booska-P, Hypebeast)
Rituel / moment d'usage        ★★★★   (Morning Brew, NowThis)
Étymologie (latin/grec)        ★★★    (Vox, Axios)
Descriptif SEO                 ★★     (Footmercato — volume requis)
Générique de niche             ★      (GOAL — déconseillé aux nouveaux)

RÈGLES TRANSVERSALES
- ≤ 3 syllabes, ≤ 10 caractères, handle court, prononçable au téléphone
- Nom > 7 lettres → symbole d'avatar obligatoire jour 1
- Le nom est une promesse compressée, pas une description
- Penser le nom sur un hoodie ET dans une phrase orale ("t'as vu sur X ?")
- Blaise ne vérifie PAS les disponibilités → checklist systématique :
  handle Instagram, domaine, recherche INPI/EUIPO, recherche Google stricte
```

# PARTIE C — CIBLE, POSITIONNEMENT, TON

## La cible en une phrase (jamais un persona de 2 pages)

Formule : **"[qui] qui veulent [quoi] sans [friction]"**

Exemples calibrés sur des médias réels :
```
Brut          les 18-34 qui veulent comprendre l'actu sans la TV de leurs parents
Morning Brew  les jeunes actifs qui veulent le business sans le jargon du FT
433           les fans de foot qui veulent la culture foot mondiale sans les tunnels tactiques
Vox           les curieux qui veulent le POURQUOI de l'actu sans le flux du breaking
Konbini       les 15-30 qui veulent la pop culture sans le sérieux des médias installés
Booska-P      la communauté rap FR qui veut son actu par les siens, sans filtre mainstream
```

La phrase-cible calibre ensuite mécaniquement :
- Tutoiement/vouvoiement des posts
- Niveau de vulgarisation des deep dives
- Les référents culturels autorisés
- Les créneaux de publication

## Les jobs-to-be-done d'un média (pourquoi on suit un compte)

```
1. S'INFORMER VITE        → formats Actu, alertes, rythme élevé
2. COMPRENDRE EN PROFONDEUR → Deep Dives, sauvegarde, autorité
3. APPARTENIR             → codes communautaires, citations, ton complice
4. SE DIVERTIR            → émotion, punchlines, formats légers
5. PARAÎTRE INFORMÉ       → contenus partageables, stats, récaps screenshotables
```
Un média sert 1-2 jobs PRINCIPAUX. Blaise identifie lesquels, et ça
détermine le mix de formats Forje (jobs 1+3 → breaking mix ; jobs 2+5 →
analyse mix).

## Le positionnement : la carte à 2 axes

Axes les plus discriminants pour un média :
**VITESSE ↔ PROFONDEUR** et **SÉRIEUX ↔ COMPLICE**

```
                    SÉRIEUX
                       │
        Les Échos      │      Le Monde
        Bloomberg      │      Vox · Axios
                       │
VITESSE ───────────────┼─────────────── PROFONDEUR
                       │
        Brut · L'Équipe│      Konbini (dossiers)
        Oh My Goal     │      Morning Brew
                       │
                    COMPLICE
```

Méthode Blaise : placer les 5 concurrents du client sur la carte →
chercher le quadrant (ou la frontière) le moins occupé → formuler le
positionnement : **"Le seul média [niche] qui [différence] pour [cible]."**
Un positionnement qui pourrait être signé par un concurrent n'en est pas un.

## Le ton de voix : 4 curseurs

```
FORMEL      ─────○────  FAMILIER      (tutoiement ? argot ?)
FACTUEL     ──○───────  ÉMOTIONNEL    (data ou punchline ?)
SÉRIEUX     ────────○─  JOUEUR        (humour autorisé ?)
EXPERT      ─────○────  ACCESSIBLE    (jargon ou vulgarisation ?)
```
Blaise règle les 4 curseurs AVEC le client (exemples concrets à l'appui :
"pour cette actu, version factuelle : X / version émotionnelle : Y —
laquelle te ressemble ?"). Le réglage alimente tone_tags et le mood, et
donc directement les titres générés par Forje.
Règle : les curseurs sont FIXES ensuite. Un ton qui bouge selon l'humeur
du CM détruit la reconnaissance — c'est le rôle de Forje de le verrouiller.

# PARTIE D — LES 10 LEÇONS MAÎTRESSES (volet marque)

1. **Plateforme → nom → visuel.** Jamais l'inverse. Un logo sans
   positionnement est une décoration.
2. **Un archétype dominant, un secondaire max.** Trois archétypes = zéro
   personnalité.
3. **Le meilleur nom est une promesse compressée** (Brut), pas une
   description (ActuFootballFrance).
4. **Chercher le nom qui contient sa forme** (Pitchfork) quand naming et
   logo se font ensemble.
5. **La cible tient en une phrase** [qui/quoi/sans friction] — et cette
   phrase calibre mécaniquement le ton, la vulgarisation, les créneaux.
6. **Positionner = trouver le quadrant vide** sur la carte
   vitesse/profondeur × sérieux/complice des 5 concurrents.
7. **Un positionnement signable par un concurrent n'en est pas un.**
8. **1-2 jobs-to-be-done principaux** — et ils déterminent le mix de
   formats Forje.
9. **Les 4 curseurs de ton se règlent une fois puis se verrouillent** —
   la reconnaissance naît de la répétition.
10. **Le test final : masque le logo.** Si on ne reconnaît pas le média
    à un post, la marque n'existe pas encore.
