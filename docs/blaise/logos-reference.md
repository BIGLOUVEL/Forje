# BLAISE — Les 50 logos analysés
## Document de référence de la Design Knowledge Base

Ce document est la TRACE de l'expertise injectée dans Blaise : 50 identités
de médias et marques de contenu populaires sur les réseaux, analysées selon
une grille unique. C'est la matière première dont les règles du module
LOGO_KB sont distillées.

Note de méthode : analyses basées sur les identités telles qu'établies et
connues — les marques évoluent, certains hex sont des approximations (≈).
La valeur de ce doc est dans les PATTERNS transversaux, pas dans le détail
pixel de chaque logo.

## LA GRILLE D'ANALYSE (appliquée aux 50)

Pour chaque logo :
- **Archétype** : monogramme plein / symbole pur / symbole-dans-lettre /
  wordmark / badge / visage (marque personnelle)
- **Couleurs** : la signature + le système
- **Typo** : famille et caractère
- **Test 110px** : comment l'identité survit en avatar rond Instagram
- **Leçon** : ce que Blaise en retient

# ACTU & NEWS — FRANCE (11)

**1. Brut**
Archétype : wordmark court ("brut" bas-de-casse). Couleurs : noir/blanc
absolus. Typo : sans géométrique bold, bas-de-casse = proximité.
110px : 4 lettres, graisse massive → lisible tel quel en avatar.
Leçon : un nom de 4-5 lettres bold peut être son propre monogramme.
Le bas-de-casse casse la distance avec l'audience jeune.

**2. Loopsider**
Archétype : symbole pur (boucle) + wordmark compagnon. Couleurs : bleu
électrique ≈#2745F5 sur blanc. Typo : sans moderne rond.
110px : la boucle seule en avatar — le nom est trop long.
Leçon : nom long (9 lettres) → le symbole DOIT exister dès le jour 1.
Le symbole encode le nom (loop) : cohérence nom/forme.

**3. HugoDécrypte**
Archétype : visage (marque personnelle) + wordmark sobre. Couleurs :
noir/blanc, accents jaunes. Typo : sans neutre.
110px : le VISAGE de Hugo est l'avatar — pas un logo dessiné.
Leçon : pour une marque personnelle, le visage bat n'importe quel logo.
Blaise doit demander "média de marque ou média incarné ?" avant de designer.

**4. Konbini**
Archétype : monogramme plein ("K" blanc sur noir). Couleurs : noir/blanc,
la couleur vient du CONTENU. Typo : sans grotesque bold.
110px : le K massif, parfait.
Leçon : identité N&B + contenus ultra-colorés = le logo cadre, le contenu
vibre. Système durable qui ne se démode pas.

**5. Explicite**
Archétype : wordmark bold. Couleurs : rouge urgence ≈#E5322D + noir.
Typo : sans condensé droit, autorité.
110px : "E" seul en avatar.
Leçon : le rouge est LE code de l'info immédiate en France — jouer avec
ou s'en démarquer est une décision stratégique, jamais un hasard.

**6. Le Monde**
Archétype : wordmark sérif historique. Couleurs : noir/blanc.
Typo : sérif à empattements marqués (héritage presse).
110px : le "M" sérif seul.
Leçon : le sérif signale l'héritage et la profondeur — il fonctionne
pour un média qui VEND cette profondeur, à condition d'un monogramme épais.

**7. Les Échos**
Archétype : wordmark. Couleurs : rouge sombre ≈#B01F24 + blanc.
Typo : sérif/sans hybride sobre.
110px : monogramme "E" rouge.
Leçon : l'éco/finance française utilise le rouge sombre (sérieux) là où
l'actu chaude utilise le rouge vif (urgence). La NUANCE de la couleur
porte le positionnement.

**8. Libération**
Archétype : bloc wordmark (cartouche rouge, texte blanc). Couleurs :
rouge ≈#E4032E + blanc. Typo : sans bold serré.
110px : le cartouche rouge se lit comme une forme.
Leçon : le "bloc plein + texte en négatif" transforme un wordmark en
quasi-symbole — trick puissant pour les noms moyens (10 lettres).

**9. Franceinfo**
Archétype : wordmark bas-de-casse + ponctuation ("franceinfo:").
Couleurs : jaune ≈#F5C300 + noir/gris anthracite. Typo : sans humaniste.
110px : "f:" — les deux-points font partie de la marque.
Leçon : un signe de ponctuation peut devenir un actif de marque
(le ":" = "la suite de l'info"). Détail typographique = différenciation.

**10. 20 Minutes**
Archétype : monogramme chiffré ("20" dans un bloc). Couleurs : vert
≈#37A93C + blanc. Typo : sans rond accessible.
110px : le "20" plein cadre.
Leçon : les chiffres sont des logos redoutables — mémorisables,
lisibles, uniques dans un feed de lettres.

**11. AJ+**
Archétype : wordmark-monogramme ("AJ+"). Couleurs : orange-vermillon
≈#FA4616 + blanc. Typo : sans géométrique bold.
110px : 3 caractères dont un "+", parfait.
Leçon : le "+" est un signe chargé (plus de contexte, communauté,
modernité). 2 lettres + 1 signe = formule d'avatar idéale.

# ACTU & NEWS — INTERNATIONAL (9)

**12. NowThis**
Archétype : wordmark incliné. Couleurs : bleu ≈#00B2FF + blanc.
Typo : sans bold italique (mouvement).
110px : "N" incliné.
Leçon : l'italique = vitesse/immédiateté, même hors sport. L'angle
d'inclinaison (8-12°) doit être constant sur toute l'identité.

**13. Vice**
Archétype : wordmark. Couleurs : noir/blanc. Typo : "VICE" en caps
condensé irrégulier, presque brut.
110px : 4 lettres, tient en avatar.
Leçon : l'imperfection typographique assumée peut ÊTRE l'identité
(contre-culture). Mais c'est un choix éditorial, pas un accident.

**14. Vox**
Archétype : wordmark court. Couleurs : jaune ≈#FFF200 + noir.
Typo : sans bold serré.
110px : "Vox" entier sur bloc jaune.
Leçon : jaune + noir = le contraste le plus vu de loin de tout le
spectre. Pour un média "explication", ça dit : clarté.

**15. Axios**
Archétype : wordmark + monogramme "A". Couleurs : noir/blanc, accents
bleus. Typo : sans moderne, le slash "/" utilisé en marqueur éditorial.
110px : le "A".
Leçon : un caractère utilitaire (le slash des "smart brevity") peut
structurer toute la grammaire visuelle au-delà du logo.

**16. Morning Brew**
Archétype : symbole (tasse de café) + wordmark. Couleurs : bleu nuit
≈#1F2E4A + blanc/crème. Typo : sérif chaleureux.
110px : la tasse seule.
Leçon : un objet du quotidien comme symbole rend la marque VIVABLE
(rituel du matin). Le symbole raconte l'usage, pas le contenu.

**17. BBC News**
Archétype : badge (3 blocs lettrés). Couleurs : blanc sur noir,
rouge pour News. Typo : sans institutionnel.
110px : les 3 blocs tiennent — chaque lettre a sa case.
Leçon : le système "1 lettre = 1 bloc" scale parfaitement en petit.
Institutionnel mais imbattable en lisibilité.

**18. CNN**
Archétype : wordmark-symbole (le ruban continu). Couleurs : rouge
≈#CC0000 + blanc.
110px : les 3 lettres liées se lisent comme UNE forme.
Leçon : ligaturer les lettres transforme un sigle en symbole —
mais exige un travail typographique sur mesure.

**19. Al Jazeera**
Archétype : symbole pur (calligraphie en goutte dorée). Couleurs :
or ≈#FAA61A + bleu nuit.
110px : la goutte calligraphique, unique au monde.
Leçon : un symbole fort traverse les langues et les alphabets —
argument clé si le média vise une audience internationale.

**20. The Washington Post**
Archétype : wordmark blackletter (gothique). Couleurs : noir/blanc.
110px : "WP" empilé en avatar (le wordmark complet est impossible).
Leçon : même les identités les plus patrimoniales capitulent devant
les 110px : TOUT le monde finit avec un monogramme d'avatar.

# SPORT — FRANCE (7)

**21. L'Équipe**
Archétype : bloc wordmark italique. Couleurs : rouge ≈#E42618 + blanc.
Typo : sans bold italique — la référence vitesse.
110px : cartouche rouge, texte en négatif.
Leçon : LE standard du sport français. S'en écarter = se différencier,
s'en approcher = crédibilité immédiate. Les deux sont jouables.

**22. So Foot**
Archétype : wordmark. Couleurs : noir/blanc. Typo : caps serré, ton
irrévérencieux porté par l'édito plus que par le logo.
110px : "SO" en avatar.
Leçon : un logo sobre peut porter une marque insolente — la
personnalité peut vivre dans le contenu, le logo reste le cadre.

**23. Footmercato**
Archétype : monogramme "FM". Couleurs : bleus ≈#1B4DB1.
110px : le FM compact.
Leçon : le bleu en sport dit "info fiable" (vs le fluo qui dit
"culture jeune"). Le mercato = de l'info, le choix est cohérent.

**24. Actufoot**
Archétype : symbole-dans-lettre (ballon dans la contreforme).
Couleurs : noir + accent vif.
110px : la lettre-ballon.
Leçon : le ballon dans la lettre est LE trope du foot — efficace mais
saturé. Blaise doit le proposer en le signalant : "classique, safe,
mais attendu".

**25. RMC Sport**
Archétype : blocs lettrés. Couleurs : noir/blanc/rouge.
110px : "RMC" en blocs.
Leçon : la filiation radio/TV (blocs, caps) rassure sur le sérieux —
pattern "média installé".

**26. Winamax Sport**
Archétype : monogramme "W". Couleurs : rouge ≈#E30613 + blanc/noir.
110px : le W massif.
Leçon : une seule lettre bien dessinée suffit à porter une marque
énorme. Le W a des coupes franches = énergie.

**27. Oh My Goal**
Archétype : wordmark + monogramme. Couleurs : jaune/noir énergiques.
110px : monogramme sur fond plein.
Leçon : les médias foot "social-first" (nés sur les réseaux) sont
systématiquement plus colorés et plus bold que les médias hérités —
c'est un marqueur générationnel à exploiter.

# SPORT — INTERNATIONAL (10)

**28. ESPN**
Archétype : wordmark italique. Couleurs : rouge ≈#D50A0A + blanc.
110px : 4 lettres italiques, tient.
Leçon : la matrice mondiale du sport TV. Italique + rouge + caps =
lu "sport" instantanément partout sur la planète.

**29. SportsCenter**
Archétype : monogramme "SC" (système ESPN). Couleurs : rouge/blanc.
110px : SC compact.
Leçon : les sous-marques héritent du système (couleur, italique) avec
leur propre monogramme — pattern pour les médias multi-comptes.

**30. Bleacher Report**
Archétype : monogramme à séparateur "B/R". Couleurs : noir/blanc.
110px : B/R, le slash aère.
Leçon : le slash entre deux lettres crée un rythme et une modernité
qu'un simple "BR" n'a pas. Micro-détail, macro-différence.

**31. House of Highlights**
Archétype : symbole (maison/panneau stylisé) + sigle. Couleurs :
orange basket + noir.
110px : le symbole seul.
Leçon : nom long (17 lettres) né sur Instagram → le symbole était
vital dès le départ. La couleur emprunte au ballon de la niche.

**32. Overtime**
Archétype : monogramme "OT". Couleurs : noir/blanc, accents vifs.
110px : OT massif.
Leçon : marque construite POUR la génération TikTok/IG — monogramme
épais, zéro fioriture, déclinable en merch. Le logo est pensé comme
un logo de streetwear, pas de média : c'est le futur du sport social.

**33. 433**
Archétype : chiffres ("433"). Couleurs : sombre + accents.
110px : trois chiffres, imbattable.
Leçon : 4-3-3 = une formation tactique → le nom EST un signe de
reconnaissance communautaire. Le meilleur naming encode un savoir
partagé de la niche.

**34. GOAL**
Archétype : wordmark court. Couleurs : blanc sur sombre.
110px : GOAL entier.
Leçon : un mot générique de la niche en caps bold = clarté absolue,
mais différenciation faible → tout repose alors sur la couleur et
la constance.

**35. SPORF**
Archétype : wordmark court inventé. Couleurs : contrastes vifs.
110px : 5 lettres bold.
Leçon : un néologisme court (SPORF = sport + f) est ownable à 100% —
aucune concurrence SEO, handle disponible, marque déposable.

**36. DAZN**
Archétype : wordmark custom (le Z traversé). Couleurs : noir/blanc.
110px : 4 lettres, le Z distinctif accroche.
Leçon : UNE lettre customisée suffit à rendre un wordmark unique
et mémorisable. Pas besoin de tout redessiner.

**37. Sky Sports**
Archétype : wordmark (héritage TV, effets historiques).
110px : simplifié en aplat pour le digital.
Leçon : les marques TV héritées ont dû APLATIR leurs logos pour les
réseaux — preuve par l'histoire que le flat n'est pas une mode mais
une contrainte du médium. Blaise ne génère jamais l'inverse du sens
de l'histoire.

# CULTURE / MUSIQUE / STREET (7)

**38. Complex**
Archétype : wordmark. Couleurs : noir/blanc. Typo : sans serré bold.
110px : "C" en avatar.
Leçon : le N&B en culture street = intemporalité, et laisse les
collabs/covers porter la couleur. Même logique que Konbini.

**39. Booska-P**
Archétype : monogramme/bloc. Couleurs : rouge/noir.
110px : monogramme plein.
Leçon : le rap FR emprunte le rouge/noir de l'urgence ET l'esthétique
label de musique — un média de niche peut hybrider deux grammaires.

**40. Highsnobiety**
Archétype : wordmark long → monogramme "H" en avatar.
Couleurs : noir/blanc strict.
Leçon : le minimalisme absolu est un positionnement luxe/curation.
Moins le logo en dit, plus il dit "on sait".

**41. Hypebeast**
Archétype : wordmark + monogramme "H"/"HB". Couleurs : noir/blanc.
Leçon : même niche que Highsnobiety, même solution — quand une niche
converge visuellement, la différenciation passe par le CONTENU et le
ton, et le logo devient un standard de catégorie.

**42. Pitchfork**
Archétype : symbole-dans-lettre (le "P" fourche/trident).
Couleurs : noir/blanc.
110px : le glyphe seul, unique.
Leçon : le meilleur symbole-dans-lettre du corpus — le nom (pitchfork)
devient littéralement la forme de la lettre. Nom + forme + sens
alignés = graal du branding.

**43. Genius**
Archétype : wordmark. Couleurs : jaune ≈#FFFF64 + noir.
110px : "G" sur jaune.
Leçon : le jaune fluo possédé à 100% — quand une marque s'approprie
une couleur assez fort, la couleur SEULE devient le logo (un screenshot
jauni "fait" Genius).

**44. The Fader**
Archétype : monogramme "F" / wordmark. Couleurs : noir/blanc.
Leçon : confirmation du pattern culture = N&B + typographie forte.
Trois occurrences (Complex, Highsnobiety, Fader) = règle de niche.

# TECH / ÉCO (6)

**45. TechCrunch**
Archétype : monogramme "TC" ligaturé. Couleurs : vert ≈#0A9E01 + noir.
110px : le TC compact.
Leçon : le vert en tech = croissance/terminal. La ligature TC fait
symbole. Deux lettres ligaturées > deux lettres posées côte à côte.

**46. The Verge**
Archétype : symbole géométrique (V angulaire) + wordmark.
Couleurs : dégradés magenta/orange MAIS sur des formes géométriques simples.
Leçon : l'exception qui confirme la règle anti-dégradé — un dégradé
fonctionne UNIQUEMENT sur une forme ultra-simple et à condition d'être
la signature centrale de la marque. Blaise peut l'autoriser dans ce cas
précis, en le disant.

**47. Wired**
Archétype : wordmark à cases alternées (lettres en blocs inversés).
Couleurs : noir/blanc.
Leçon : le rythme positif/négatif dans un wordmark crée une texture
reconnaissable de loin — technique typographique pure, zéro symbole.

**48. Bloomberg**
Archétype : wordmark. Couleurs : noir/blanc. 110px : "B".
Leçon : la finance mondiale = sobriété radicale. La confiance se
signale par l'absence d'effet.

**49. Business Insider**
Archétype : monogramme "BI"/wordmark. Couleurs : bleu nuit + blanc.
Leçon : le bleu nuit = le costume du business — moins agressif que
le noir, plus sérieux que le bleu vif.

**50. Sifted**
Archétype : wordmark. Couleurs : corail ≈#FF6B5E — unique dans sa niche.
Leçon : dans une niche saturée de bleu nuit (éco/startup), le corail
de Sifted est la démonstration parfaite de la différenciation par la
couleur seule. Choisir sa couleur = d'abord regarder celles des voisins.

# SYNTHÈSE STATISTIQUE DU CORPUS

```
ARCHÉTYPES (sur 50)
Monogramme (plein/chiffré/ligaturé)   ~40%
Wordmark (dont courts ≤5 lettres)     ~34%
Symbole (pur ou dans-lettre)          ~16%
Badge/blocs                            ~6%
Visage (marque personnelle)            ~4%
→ En avatar 110px : ~90% du corpus finit en monogramme ou symbole,
  même quand le logo "officiel" est un wordmark.

COULEURS SIGNATURES PAR NICHE
Actu chaude : rouge vif (5/11 FR) · Éco : rouge sombre, bleu nuit
Sport hérité : rouge + italique · Sport social-first : fluo/jaune/orange
Culture street : noir/blanc quasi systématique (4/7)
Tech : vert, magenta, mais surtout différenciation intra-niche

TYPO
Sans-serif bold : ~80% du corpus · Italique : quasi-exclusif au sport
et à l'immédiateté · Sérif : uniquement héritage presse et rituels
premium (Le Monde, Morning Brew, WaPo)

NOMBRE DE COULEURS DANS LE LOGO
1 couleur + N/B : ~70% · 2 couleurs : ~25% · 3+ : ~5% (héritage TV)
```

# LES 12 LEÇONS MAÎTRESSES (ce que Blaise a intériorisé)

1. **Tout finit en monogramme.** Même le Washington Post. Designer
   l'avatar 110px D'ABORD, le reste ensuite.
2. **Pas de texte par défaut.** Le mark vit seul ; le wordmark est un
   compagnon sur demande. (Règle produit Forje, validée par l'usage :
   90% du corpus vit en monogramme/symbole sur Instagram.)
3. **La couleur se choisit en regardant les voisins.** Sifted corail
   dans un océan bleu nuit ; un média foot peut fuir le rouge L'Équipe.
   Première question palette : "qui sont tes 5 concurrents directs ?"
4. **La nuance de couleur porte le positionnement.** Rouge vif =
   urgence, rouge sombre = autorité éco. Même teinte, deux messages.
5. **Un détail typographique peut être toute la marque.** Le ":" de
   franceinfo, le "/" de B/R, le Z de DAZN, les cases de Wired.
   Customiser UNE chose, pas tout.
6. **Nom long = symbole obligatoire dès le jour 1** (Loopsider,
   House of Highlights). Nom ≤5 lettres bold = le nom peut suffire
   (Brut, Vox, GOAL).
7. **Les chiffres et signes battent les lettres** en mémorisation
   (20, 433, AJ+, +, :). S'il y a un code communautaire chiffrable,
   l'explorer.
8. **Le N&B est un choix offensif, pas un défaut** : il cadre un
   contenu coloré (Konbini, Complex) et signale la curation
   (Highsnobiety). À proposer activement aux médias culture.
9. **Marque incarnée ≠ marque média.** Si une personne EST le média,
   le visage est l'avatar et le logo devient secondaire (HugoDécrypte).
   Question à poser systématiquement.
10. **Social-first = plus bold, plus fluo, plus simple** que les
    marques héritées (Overtime vs ESPN, Oh My Goal vs L'Équipe).
    L'histoire du flat design est une contrainte du médium, pas une mode.
11. **L'alignement nom-forme-sens est le graal** (Pitchfork : le nom
    est la forme). Quand Blaise fait aussi le naming, chercher un nom
    qui DESSINE quelque chose.
12. **Les exceptions se gagnent** : un dégradé (The Verge) ou une
    imperfection (Vice) fonctionnent uniquement comme signature
    centrale et assumée — jamais comme décoration. Blaise peut les
    accorder à un client qui les veut, en expliquant la condition.

## USAGE DE CE DOCUMENT

- Ce doc est la SOURCE. Le module lib/blaise/knowledge/logos.js en est
  la distillation opérationnelle (les règles + prompts).
- Si tu veux enrichir Blaise : ajoute des analyses ici avec la même
